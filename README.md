# ZFIT — More Outfits. Same Wardrobe.

Official landing and waitlist page for **ZFIT** ([zfits.in](https://zfits.in)).

## Features
- **Pure Web Stack**: Built with clean, accessible HTML5, modern vanilla CSS3, and lightweight vanilla JavaScript.
- **Zero Build Dependencies**: Lightning fast loading (< 50ms), zero node build steps required.
- **Interactive Waitlist**: Live client-side email validation, spot reservation, local storage persistence, and referral link generation.
- **Dual Deployment Ready**:
  - **GitHub Pages**: Automatically deployed via GitHub Actions workflow directly to custom domain `zfits.in`.
  - **Vercel**: Instant zero-config static deployment via `vercel.json`.

## Custom Domain
- Configured domain: `https://zfits.in`
- CNAME record: `zfits.in`
